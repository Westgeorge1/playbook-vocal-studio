LIMITS (browser)
 - Latency: browsers report output latency inaccurately (Bluetooth worst).
   Calibration fixes this per device, but it lives in this browser's storage
   (re-do after clearing site data or on another browser). Tap-along includes
   human timing (repeat 8+ taps); loopback is more accurate.
 - Stopped-transport phrase recording still uses MediaRecorder (as in 0.14);
   its start offset can vary by a few ms on some phones. Punch and loop takes
   use AudioWorklet capture with sample timestamps.
 - Input monitoring adds the device's round-trip delay (often 20–60 ms wired,
   150–300 ms Bluetooth). Off by default.
 - Mic gain is a digital gain stage; web pages cannot change the phone's
   hardware mic level, and gain cannot fix clipping that already happened in
   the hardware. Echo cancel / noise suppression / AGC stay off as before.
 - The fake test microphone cannot loop the output back to the input, so the
   loopback test was verified with a synthetic capture plus a "clear retry
   message" check; real-device loopback is still to be tried.
 - Not yet tested on a physical phone, real mic or Bluetooth headphones.
