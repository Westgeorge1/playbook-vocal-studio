PLAYBOOK VOCAL STUDIO 0.14.0 — DAW LAYOUT (2026-10-18)

Based on phone 0.13.0. Layout/markup/CSS/wiring only. worker.js, phrase-core.js, phrase-worker.js and the WASM engine (0.12.1) are byte-identical to 0.13.0.
New files: daw.css, daw.js, tests-daw/ (audit + smoke scripts and results), screens/.

WHAT'S NEW
- Top menu bar: File (backing, import, phone recorder, project, session window, new/clear/undo clear, Save/Export with every quick save + custom export, project with every take, recovery), Edit (context Undo/Redo, phrase actions, comp take, reset settings), View (zoom, tabs, dock, Smart Guide), Help (shortcuts, how recording works, about).
- Transport: back-to-start, play/pause, NEW Stop (2nd press = back to 0:00; stops a recording and keeps the attempt), big Record (records selected phrase; if that phrase is already chosen and the resume line is past it, starts the next phrase there), NEW Loop (ruler region › selected phrase › 4 bars from the playhead), clock in ms + bar/beat (from CHAIN BPM, 4/4), BPM + key display (TUNE key), MIC + OUT meters, listen switch, context-aware Undo/Redo (takes / wave edit / sound & notes).
- Timeline: ruler with bars and times, playhead, gold resume line; click = seek + set resume, drag ruler = loop region (right-click clears); BACKING lane waveform + M/S/level; VOCAL lane (applied vocal waveform, phrase regions with name, ✓ when chosen, take count, chosen take waveform) + M/S/level/record-arm; Take 1..N lanes with each phrase’s attempts (score %, CHOSEN, SUGGESTED, INCOMPLETE, ‘analysing…’); Comp take lanes for EDIT takes; zoom −/Fit/+, Ctrl+wheel zoom, horizontal scroll.
- Bottom dock: NOTE EDITOR, WAVE EDIT, COMPARE REFERENCE (collapsible).
- Right inspector: PHRASE, CLEAN, TUNE, CHAIN, DETAIL, MIX + SAVE / EXPORT.
- Shortcuts (ignored while typing): Space, Enter/Home, R, L, Ctrl/⌘+Z, Ctrl/⌘+Shift+Z / Ctrl+Y, Ctrl/⌘+S, 1–6, +/−, ?, Esc.
- Phone (<900 px): sticky compact transport, lanes scroll sideways, inspector and dock become full-width tab panels below.

CHANGES TO THE 0.13 SCRIPT (index.html)
- Version strings 0.13.0 -> 0.14.0 (title, worker cache keys, project 'savedBy', READ-ME text). Project format is unchanged (version 9).
- startPlayback: vocal and backing gains are multiplied by the DAW monitor gains (mute / solo / vocal fader). These only apply to normal playback and the new DAW loop. Matched take, guide, detail, reference and custom A/B comparisons are untouched. Recording monitoring is untouched apart from the existing backing switch and level.
- Backing level slider: live gain also respects backing solo-mute.
- showPage() is replaced at runtime by daw.js: record->PHRASE, edit->WAVE EDIT, clean/tune/chain->tabs, save->export window; 'open' stays on the timeline.

TWO TAKES SYSTEMS (requested merge)
The two engines are kept separate, because merging their data was too risky:
- Phrase takes (RECORD, phrase-core) are drawn as the Take 1..N lanes and are chosen on the timeline.
- EDIT comp takes (worker engine, whole-song takes used passage by passage) are drawn as separate 'Comp take N' lanes in the same area. Clicking one opens it in WAVE EDIT › TAKES/COMP, where 'Use selected take' works as before.
Merging them would mean changing project formats and engine state, so it was not done.

MONITOR MIX NOTES
- Backing M = the existing 'Include backing during playback & recording' switch, so it also mutes the backing in your headphones while recording. Backing level = the existing headphone level.
- Vocal fader (0-150 %), vocal M/S and backing S change what you hear only. They are not saved and not exported. The exported loudness is set by VOCAL LEVEL on CHAIN, and the rough mix uses the CHAIN 'Mix with your beat' settings as before.

NOT VERIFIED / RISKS
- A real microphone, audibility, Bluetooth latency and real touch use on a phone were not tested. Recording was smoke-tested with Chrome's fake microphone (a beep) only.
- The analyzer gives the fake-mic beep no score ('—'), because it has no stable sung notes. Scores on real singing were not seen.
- The take-lane score is the analyzer's internal 0-100 ranking value, shown only to help you choose; it is not a quality verdict. The full measurements are still on the PHRASE take cards.
- Timeline waveforms come from the applied vocal before timing edits, so after big timing edits they can be slightly off. Audio is not affected.
- Page fonts still load from Google Fonts, as in 0.13; offline, the app falls back to system fonts.
- The vocal fader, mute and solo are kept only for the current session.
