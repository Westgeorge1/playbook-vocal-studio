HOW TO REPEAT
Set PVS_CHROME to a Chromium executable, use Playwright, and serve the studio over HTTP(S). The tests launch loopback servers. For the recording, pop-out, deletion and restoration suites, place the source in a directory named beta under the test server root. PVS_TEST_OUT selects a results directory.
- tests-0.32.3/upgrade.cjs expects PVS_OLD_MAIN (unpacked 0.14.0) and PVS_OLD_BETA (unpacked 0.32.2).
- tests-0.32.3/playback.cjs expects PVS_REFERENCE_DIR, a previously released unpacked source directory, and compares that version with this release in the same browser.
- Use tests-0.32.3/{cleanup,recording,restore,windows}.cjs and the existing tests-0.32.0/{tuning,editors,workspace-editor}.cjs and tests-0.31.11/delete.cjs for the application suites.

Physical Android microphones, Bluetooth/headphone routing, latency and subjective listening on a real performance remain device checks.
