TUNING
Import a fresh vocal to use the approved original tuner sound. New vocals start
with Classic Smooth on at 25%, Keep blue notes off. This alone is not either
complete preset: open TUNE > Open note editor > Vocal tuning presets.

1. Check the key/scale and reference against the song or backing. The detected
   key is a suggestion. Use detected key if appropriate, then apply a preset.
   The approved reference recording used G major, A=440; other songs can differ.
2. Start with Snap all + Smooth 25% (the primary button).
   Alternative: 85% correction + Smooth 25%.
   High notes (about D#4 and above): in the note editor, Note detection >
   High-note fix stops them being read an octave low, which can add a rough
   undertone. Turn it on before applying the preset; compare by ear.
3. Listen, select any note that needs fixing and adjust only that note.
   Applying a whole-vocal preset again can change manual pitch choices.
4. Use FINAL for the full vocal chain and Finish & check for export.

Both presets are explicit whole-vocal commands, not continuously repeated
centre correction. The separate Snap all command retains the current Smooth
setting. Correct pitch still acts only on selected notes, including one note.

are labelled in the editor. Import a fresh vocal for the approved sound; the
update does not silently re-analyse and discard your saved note edits.

is still available in TUNE. Both tuner states remain in the project. For the
complete prior runtime, run rollback/0.31.0/serve.py in that folder and open
your pre-update project backup. The reviewed 0.29 runtime ZIP is also kept.
