How the suites are set up in 0.17.1
  - t171.py runs with the new default ("Stop at part end: OFF": you record until you press Stop).
  - The older suites (t17, sessA/B/C/D/P, phone17, polish17, old17) were written around takes that stop by
    themselves at the part end. They now run with "Stop at part end: ON" (set in h.py), which is exactly the
    0.17.0 behaviour, so they keep checking everything else unchanged.

Bugs found by the new tests and fixed before this run
  - Stopping a punch-in or loop recording hung ("lat is not defined") because of a misplaced comment in the
    new code. Fixed.
  - When a part grew, its new end could be rounded 0.5 ms past the end of the take, so the take did not
    "cover" the part and could not be chosen. The end is now rounded down.
  - The safety limit used a stereo size estimate and came out at about 5.7 minutes. It is now 10 minutes.
  - Desktop 1366: the longer hint text pushed "Delete unchosen takes" below the screen; phone 360: the new
    switch made the button grid wider than the screen. Shorter hint, Redo + Stop-at-end share a row, labels wrap.
  - Test fixes: Undo replaces the whole workspace object, so the test now reads the new one; the status line
    is read after it has mirrored the take message.

Not tested here: a real phone, real microphone, real headphones, listening by ear.
