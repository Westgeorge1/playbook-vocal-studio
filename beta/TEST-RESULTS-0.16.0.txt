PLAYBOOK VOCAL STUDIO 0.16.0 — TEST RESULTS (2026-10-18)
Tested in headless Google Chrome with a fake microphone (Chrome test device:
a repeating beep), on a desktop window (1600x1000 / 1440x900) and a phone-size
touch window (390x844). Not tested on a real phone, a real mic or Bluetooth.

SUMMARY
  New RECORD & COMP tests (tests-0.16/test16.py) ......... 110 of 110 passed
  0.15 feature tests re-run on 0.16 (regress/test15) ..... 85 of 85 passed
  0.15 smoke test re-run on 0.16 (regress/smoke15) ....... 61 of 61 passed
  Control audit 0.15 -> 0.16: 437 control ids, 0 missing, 0 lost handlers, 0 unreachable
  Control audit 0.14 -> 0.16: 352 control ids, 0 missing, 0 lost handlers, 0 unreachable
  Sound engine files: byte-identical to 0.15.0 (phrase-core.js, worker.js,
  phrase-worker.js, engine-wasm.*, daw.css). daw.js, rec.js, rec.css and
  rec-worklet.js differ only in the version number text.

HOW THE OLD TESTS WERE RUN ON 0.16
  0.16 opens on RECORD & COMP, so the 0.15 tests open 0.16 with ?step=polish
  (the same as clicking "2 POLISH"). Only these test edits were made: the
  port/URL, the expected version text 0.16.0, the screenshot folder, the
  output file paths, and one helper scrolls the existing track list before
  clicking a lower lane (the step bar takes ~63 px at the top, so in a 900 px
  window the 2nd take lane sits just below the visible area until you scroll).
  An extra audit with 0.16 left on RECORD & COMP (informational) shows the 0.15
  controls are all present and wired there too, just hidden until POLISH.

PROJECT COMPATIBILITY (inside test16)
  - 0.16 save -> reopen in 0.16: parts, takes and choices identical
  - 0.16 project -> opens in the 0.15 app: identical, no errors
  - project saved by the real 0.15.0 app -> opens in 0.16 as parts with takes,
    stars and 2 markers kept
  - project format still version 9; nothing new is required

THINGS FOUND AND FIXED DURING TESTING
  - Play pressed after the playhead was past the end of the song now starts from
    the top (it used to stop at once).
  - "Punch in now" from More works while the comp is playing (it now switches to
    plain playback first, as punch-in needs).
  - The take list no longer rebuilds in the middle of a click (a click could be
    lost when take analysis finished at that moment).
  - Phone: song title no longer overlaps the saved light; drag of the IN/OUT
    flags no longer throws an error on some touch events.
  - The help line uses the full width; POLISH hides the step bar copies of
    saved / Undo / Redo because POLISH has its own.

LIMITS / NOT TESTED
  - No real phone, real microphone, headphones or Bluetooth were used.
  - The fake mic only beeps, so TUNE finds no sung notes on it (same in 0.15);
    the TUNE check only confirms POLISH analysed the comp.
  - Latency compensation was checked with a set 50 ms value; the latency test
    itself needs a real mic and speaker (loopback), not possible with a fake mic.
  - Browser recording start times can vary slightly between devices.
  - "Hear my comp" also controls hearing the old vocal while recording.
  - A punch-in that does not cover a whole part makes its own small part
    ("Punch m:ss"), same rule as 0.15.
