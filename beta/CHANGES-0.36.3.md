# Playbook Vocal Studio 0.36.3 beta

Guide this vocal uses Natural Roots and Gentle Polish in Simple view. In Classic view it uses the two original approved presets. It renders a separate editor for comparisons. A Classic switch change invalidates the old choice. Smart Guide and the breath preview now measure singing on the same take and selection. The breath preview starts at 4 dB when more than 35% of the selection appears sung.

The optional AI isolation blend now compensates the two-frame delay measured in the bundled model. Long jobs yield between groups of frames so the page can respond. Studio Spectral handles saved room profiles with filters on shorter takes, warns about a periodic learned sample, and detects singing in opposite-polarity stereo. The safety meter reminds the user to check quiet consonants. Cleaning Undo and Redo update when the host finishes processing.

The Record button shows the lead-in separately. It offers Stop & keep after microphone samples have reached the recording region. Starting the audio clock alone no longer marks a take ready to keep.

During recording the studio writes approximately one second of microphone samples at a time into a separate local safety copy. After an interrupted recording, open **Song & vocals → Interrupted recordings** to download the audio up to the last completed checkpoint. A verified project save retires the safety copy. Cancelling a take discards it. The private copies are isolated by studio route. Clearing browser storage also removes safety copies.

On phones, Guide uses a shorter panel with room for the transport. The website uses local font fallbacks. For offline reopening, use **Song & vocals → Help → Prepare for offline use** while connected, and wait for confirmation. The offline cache contains public studio files. WAV downloads carry an audio MIME type.

Large full-lane POLISH can still time out. The studio names the long-lane problem and suggests polishing a shorter passage. Timeline rendering, WAV export and whole-lane POLISH have different resource requirements.
