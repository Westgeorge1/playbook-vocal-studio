# Playbook Vocal Studio 0.18.2

App version 0.18.2 · audio engine version 0.12.1 (unchanged).

Test link (serves 0.18.2): https://westgeorge1.github.io/playbook-vocal-studio/beta/
Main link (unchanged, 0.14.0): https://westgeorge1.github.io/playbook-vocal-studio/

Open it in Chrome. Two steps: **1 RECORD & COMP** (record the song part by part, pick the best take of each
part) and **2 POLISH** (clean, tune, chain, mix, export).

- Start with START-HERE.txt and RECORD-AND-TAKES.txt.
- What is new in 0.18.2 and where each control is: CHANGES-0.18.2.txt.
- Test results: TEST-RESULTS-0.18.2.txt. Tests: tests-0.18/run_all.sh (browser suites + node suites).

To host it yourself, serve all files together over HTTPS. Opening index.html straight from the disk cannot
run the workers or the microphone reliably.
