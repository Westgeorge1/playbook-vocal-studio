REFERENCE AUDIO AND TEST METHOD
The supplied 48 kHz stereo Suno vocal was measured and used as a real file
input. Its original recording was not edited or included in this package.
The controlled comparison used seconds 30-42 and a separate copy high-passed
at 450 Hz with a second-order Butterworth filter, then peak-scaled to 0.8.
This deliberate mismatch tests the direction of the suggested body adjustment;
it does not demonstrate that the reference singer or sound can be recreated.

The selected reference passage measured approximately -19.58 LUFS,
-7.55 dBTP, 9.86 seconds of voice-like activity and 2.49% side energy.
Its 14.86 dB sung-frame level range is a P90-P10 statistic; it is not LRA.
Measurements are in tests-0.27/results/supplied-reference-measurements.json.
The audio and generated browser projects/screenshots are not bundled.

REPRODUCING THE NEW CHECKS
Run node tests-0.27/reference.test.cjs.
For browser tests, install Python Playwright and set PVS_CHROME to Chromium.
Run python tests-0.27/run_browser.py edge27.py for the self-contained edges.
For the main reference workflow, also set PVS_REFERENCE_WAV to the supplied
vocal and PVS_OWN_WAV to the altered 12-second comparison fixture, then run
python tests-0.27/run_browser.py. PVS_TEST_OUTPUT chooses the output directory.
Private vocal fixtures are deliberately not distributed with the app.

NOT VERIFIED
Subjective real-singer quality, melody correctness, naturalness, physical
microphone/headphone latency, Safari/iOS, Android hardware, low-memory phones
or OS background termination. Tests used Linux headless Chromium and emulated
phone viewports. A short preview's effect state can differ from full-vocal
rendering because it has at most two seconds of lead-in. Listen to the whole
vocal after Apply and use Undo if you prefer the previous sound.

No second tuner was added. No live website was deployed.
